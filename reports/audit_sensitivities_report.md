## C. Design-only equity overlay (circularity check): the attack is SUSTAINED

The full model contains income terms, so the equity profile of the
overlooked set could be partly mechanical. Refit with all demographic
covariates removed: overlooked median income: full model $61,405, design-only $80,313, citywide $69,625; sub-$100k share: 78% / 62% / 64%.

Reading: under a design-only score the income skew of the overlooked set
disappears (and mildly reverses). The published equity profile therefore
describes the deployed score, whose predicted risk legitimately includes
neighborhood-context adjustment, and must not be presented as a finding
about street design or about the screening process. All project text is
being revised to state the profile descriptively with this mechanism
disclosed. The danger finding is unaffected: the overlooked set's forward
crash performance (temporal holdout: trend-adjusted worsening of 17%) does
not depend on how the equity profile arises.
